## Build

For building, the following packages must be installed:

- `cmake`
- `make`
- C++ compiler
- `python3`
- `python3-dev`
- `python3Packages.matplotlib`
- `python3Packages.numpy`
- `python3Packages.pybind11`
- `python3Packages.blessed`

To build the project, run

```./build.sh```
